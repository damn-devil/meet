# … — планы для двоих 💜

Веб-приложение (PWA) для пары: совместные планы, встречи с проверкой по геолокации,
Яндекс Карты, комментарии, оценки и общий пиксельный котик, которому радостно,
когда планы выполняются.

## Что умеет

- **Пара из двух человек** — первый регистрируется и создаёт пару с кодом приглашения,
  второй присоединяется по коду.
- **Планы** — название, место (отмечается на карте), дата и время, описание.
- **Яндекс Карты** — поиск заведений по названию, выбор точки на карте.
  Если ключ Яндекса не указан, автоматически используется OpenStreetMap.
- **Проверка прихода** — приложение следит за геолокацией. Когда **оба** человека
  окажутся рядом с точкой встречи (радиус + окно времени), план автоматически
  засчитывается выполненным.
- **Перенос и удаление — только с согласия обоих**. Один отправляет запрос,
  второй подтверждает.
- **Оценка встречи** — после того как встреча состоялась, каждый ставит 1–5 звёзд.
- **Котик-маскот (тамагочи)** — маленький пиксельный котик (CC0, itch.io) бегает по
  верху всех экранов и без слов показывает настроение парящими эмодзи над головой.
  Он «питается» встречами: выполненный план — радость и сердечки, пропущенный —
  грусть. Погладить котика можно кликом. Вкладка «Котик» убрана, статистика —
  в профиле.
- **Плавающее меню навигации** — круглая «пилюля» из прозрачного стекла
  (backdrop blur), откреплена от скролла, снизу по центру.
- **Фон из своего фото** — загрузите любую фотографию, она станет фоном
  приложения (хранится локально, стекло и котик остаются поверх).
- **Редактирование профиля** — имя, аватар (эмодзи **или фото из галереи** —
  грузится в Supabase Storage), «о себе», а также контакты
  **Telegram** и **iMessage**: на карточке партнёра появляются кнопки,
  которые одной кнопкой открывают чат с ним.
- **Настройки** — темы (авто/светлая/тёмная/полночь/роза/океан), акцентный цвет
  (пресеты iOS + **свой цвет** через цветовую палитру, сохраняется),
  радиус встречи, окно прибытия, запас на опоздание, iOS-переключатели уведомлений
  и автопроверки прихода.
- **PWA** — устанавливается на iPhone («На главный экран»), работает офлайн (каркас).

## Превью дизайна

Дизайн выполнен по **Apple HIG**: стеклянные поверхности (backdrop blur 40px),
системный синий `#007AFF`, плавающая круглая навигация, модальные окна-шторки снизу,
переключатели-тогглы, скругления 22px/44px.

Посмотреть дизайн офлайн (без Supabase) — просто откройте в браузере
**`design-preview.html`** (двойной клик по файлу): обычный сайт (без рамки
телефона) на цветном mesh-фоне со стеклянными карточками, котик-маскот бегает
по верху, экраны входа, планов, деталей, карты, профиля, нижняя панель «Новый план»,
тёмная/светлая тема, свой цвет акцента и фон из фото (сохраняются в localStorage).

Спрайты котика — «16 px Free Pixel Animation: Cat [6 loops]» от Zeenaz
(CC0, https://zeenaz.itch.io/free-pixel-animation-cat-6-loops).

## Архитектура

- **Frontend** — React + Vite, статический сайт на **GitHub Pages**.
- **Backend** — **Supabase** (PostgreSQL): вся бизнес-логика живёт в SQL-функциях
  (RPC), права доступа — через Row Level Security, живая синхронизация между
  партнёрами — через Supabase Realtime. Вход — по email/паролю (Supabase Auth).

```
src/
  lib/supabase.js    клиент Supabase (URL + anon-ключ из .env)
  api.js             обёртки над RPC-функциями + Realtime-подписка
  screens/           экраны (планы, карта, профиль, детали)
  components/        CatMascot (котик-маскот), Avatar, модалки
  assets/cat/        спрайты котика (CC0, itch.io)
  lib/               карта (Яндекс/OSM), темы, geo, настроение котика
  test/              тесты компонентов
supabase/schema.sql  вся схема БД: таблицы, RLS, RPC, Realtime, storage
public/              PWA (manifest, service worker, иконки)
```

## Быстрый старт (локально)

```bash
npm install
# создайте .env по образцу .env.example с данными вашего Supabase-проекта
npm run dev          # Vite на http://localhost:5173
```

## Настройка продакшена (Supabase + GitHub Pages)

### 1. Supabase

1. Создайте проект на https://supabase.com (Free-план подходит).
2. Откройте **SQL Editor**, вставьте целиком содержимое `supabase/schema.sql`
   и выполните. Это создаст таблицы, RLS-политики, RPC-функции и включит Realtime.
3. **Authentication → Providers → Email**: включите провайдера. Чтобы вход был
   мгновенным (без письма), выключите **Confirm email**. Если оставите подтверждение —
   при регистрации придёт письмо со ссылкой, после подтверждения нужно войти.
4. **Realtime**: добавьте таблицы `couples`, `tasks`, `checkins` в публикацию
   Realtime (Dashboard → Database → Replication) — либо раскомментируйте строки
   `alter publication supabase_realtime ...` в конце `schema.sql` и выполните скрипт
   ещё раз.
5. Заберите в **Settings → API**: `Project URL` (в переменную `VITE_SUPABASE_URL`)
   и `anon public` key (в `VITE_SUPABASE_ANON_KEY`).

### 2. GitHub Pages

1. Создайте репозиторий и запушьте код (ветка `main`).
2. **Settings → Secrets and variables → Actions**: добавьте секреты
   `SUPABASE_URL` и `SUPABASE_ANON_KEY` (те же значения).
3. **Settings → Pages**: Source = **GitHub Actions**.
4. Пуш в `main` запустит workflow `.github/workflows/deploy.yml`: соберёт проект
   и опубликует на `https://ВАШ_ЛОГИН.github.io/РЕПОЗИТОРИЙ/`.

Пуш дополнительно в `supabase/schema.sql` — просто перевыполните его в SQL Editor.

### Яндекс Карты (опционально)

Получите ключ на https://developer.tech.yandex.ru/ и добавьте `VITE_YANDEX_KEY`
в `.env` и в секреты GitHub Actions. Без ключа карта работает через OpenStreetMap.

## Доступ к геолокации на iPhone

Геолокация в Safari работает только по **HTTPS**. GitHub Pages выдаёт HTTPS
автоматически, так что просто:

1. Откройте адрес GitHub Pages на iPhone.
2. В Safari разрешите доступ к геолокации.
3. «Поделиться» → «На главный экран» — приложение установится как PWA.

## Настройки пары

- **Радиус встречи** — насколько близко к точке нужно подойти (по умолчанию 150 м).
- **Окно прибытия** — за сколько до/после времени можно прийти (по умолчанию ±30 мин).
- **Запас на опоздание** — на сколько можно опоздать после окна, чтобы план не стал
  «пропущен» (по умолчанию 15 мин).

Синхронизация устройств пары — в реальном времени через Supabase Realtime:
события `tasks`, `couples` и `checkins` автоматически доставляются обоим партнёрам.
